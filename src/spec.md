# Specification

## Summary
**Goal:** Build a student marks and attendance tracking system for a coaching center that allows managing student records, recording marks for different subjects and exams, and tracking daily attendance.

**Planned changes:**
- Create backend data model to store student information (name, roll number, class, contact details)
- Implement backend functionality to record and retrieve student marks by subject and exam
- Implement backend functionality to track daily attendance records (present, absent, late)
- Create frontend interface to add, view, edit, and delete student records with search/filter
- Create frontend interface to record and view student marks with performance indicators
- Create frontend interface to mark and view attendance with calendar picker and statistics
- Design professional education-focused visual theme with warm colors and clear typography

**User-visible outcome:** Users can manage a complete roster of students, record their marks across different subjects and exams, mark daily attendance, and view historical performance and attendance data through a clean, professional interface designed for an academic coaching environment.
